Editing Stranded Colorwork Charts on a Gauge-True Grid

July 2026

Colorwork is a chart editor for stranded knitting and needlepoint: paint a motif cell by cell on a grid whose cells carry the actual stitch:row aspect, see it tiled as a repeat, read it back as per-row written instructions, and get warned when a float runs longer than the catch limit. Multiple named charts persist locally, every stroke saves instantly, and the outputs are PNG export, true-physical-size printing, and copyable instructions [1].

The problem

The Image Chart converter [2] answers "turn this picture into a chart," but most colorwork doesn't start from a picture — it starts from nothing, or from a motif in the knitter's head, designed stitch by stitch. Doing that on paper hits the same two walls as always: square graph paper lies about proportions (the charted snowflake knits up squat), and a single drawn motif hides how the repeat reads — whether the tiled pattern flows or visibly seams at every join. A third failure is silent until blocking: a color that floats behind 9 stitches puckers the fabric unless it was caught, and nothing on paper flags it.

How it works

Charts are named projects in a dropdown, most recently touched first, like the row counter [3]. Set the grid (up to 120 × 160) and the cell mode — knitter's gauge (cells proportioned stitch gauge : row gauge) or square for mesh work. Then paint: Paint drags across cells, Fill floods a region, Erase returns cells to MC. The palette starts as MC plus three contrast colors and grows to twelve; removing a color returns its cells to MC. Undo reverses the last fifty strokes, fills, clears, and resizes.

Below the editor, the repeat preview tiles the motif 3 × 2 with faint seam lines — the live answer to "does this repeat flow?" The written instructions panel renders every row as run-length text, and a copy button prefixes the palette key.

The conventions

The grid follows knitting-chart convention throughout, because a chart that numbers like a book reads wrong on the needles:

  • Row 1 is the bottom row; stitch 1 is the rightmost column. Numbering sits in the right and bottom gutters, and the bold every-10 rules count from that corner — not from the top-left as ordinary graph paper would.
  • Instructions read in the round: right to left, bottom row first. A 3 × 2 test grid with one contrast cell in each corner row renders exactly as Row 1: 1 B, 2 MC then Row 2: 2 MC, 1 A.
  • Resizing anchors the bottom-right — row 1 and stitch 1 stay fixed, and the chart grows upward and to the left, the direction knitting actually grows.

The math

Float detection

In stranded knitting, a run of k stitches in one color means the other strand floats behind all k. Per row, the tool run-length encodes the cells and takes the longest run; in any row using two or more colors, a run longer than 5 stitches raises the warning, naming the row (chart numbering) and the worst run — e.g. row 7 (9 MC). Solid rows are exempt: nothing is stranded behind them.

longest run per row  =  max over RLE segments
warn when            :  row has ≥ 2 colors AND longest run > 5

With more than two colors in a row the true float length per strand is approximate (each unused color floats independently), which the tool treats as a reason to warn conservatively rather than model precisely.

Storage

A chart's cells are stored as a compact string, one hex digit per cell — which is why the palette caps at twelve colors — so a full 120 × 160 chart costs 19,200 characters in localStorage. Every stroke writes immediately; there is no save button to forget.

Editing the config

The constants at the top of the <script> block: FLOAT_MAX (5 — the catch limit, adjust to house preference), HEAVY (bold rule every 10), MAX_COLORS (12), MAX_CELLS (19,200), UNDO_DEPTH (50), and DEFAULT_PALETTE (the MC + three contrasts a new chart starts with). Charts live under colorwork.v1.

Limitations

  • It charts color per cell only — no stitch symbols (cables, decreases, lace). It is a colorwork editor, not a full stitch-chart editor.
  • The float warning is a per-row worst-run summary against a single threshold; it does not model catch placement or multi-strand float lengths exactly.
  • Charts are per-device (localStorage). The PNG and the copied instructions are the portable forms.
  • Print scale depends on the print dialog: 100% / Actual Size, verified once against a ruler, same as Graph Paper [4].
  • The repeat preview tiles edge-to-edge; motifs designed with half-drop or offset repeats are not previewed in that arrangement.
