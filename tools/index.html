Tools & Utilities

A collection of offline, zero-bloat web tools.

Fiber Arts & Crafting

  • Skein & Gauge Calculator - Computes remaining yardage from a partial skein weighed against the ball band, and converts pattern gauge to actual gauge with stitch-repeat rounding.
  • HTV Placement Calculator - Cricut heat-transfer vinyl cut-size and placement calculator across six garment types and 27 sizes, with an aspect-ratio-constrained cut, a to-scale placement diagram, and batch cut lists.
  • Row & Repeat Counter - A persistent multi-project row counter with pattern-repeat tracking, row-pinned notes, and Screen Wake Lock support.
  • Cricut SVG Vectorizer - A client-side tool to convert PNGs/JPEGs into clean SVG cut paths that runs entirely offline.
  • Local Storage Stitch Tracker - A row and stitch counter that uses local storage for offline progress tracking.
  • Yarn Substitution Calculator - A calculator that determines required skeins based on custom yardage.

Aquatics & Operations

  • Pump Room Chemistry Calculator - Chemical dosing calculator and Langelier saturation index gauge for the competition pool, instructional pool, splash pad, and spa. Computes chlorine, acid, soda ash, calcium chloride, and stabilizer doses from test-kit readings and flags Title 22 FC/pH violations.
  • Reading Queue - Offline chemical-reading capture form. Queues readings taken without signal, then batch-copies or exports CSV for entry into DigiQuatics once back in range.
  • Rotation Grid - Generates a timed lifeguard stand rotation grid from the on-shift roster and station list, with automatic break distribution and mid-shift rebuild.
  • Pool Chemistry Dosing Calculator (Alphie's Calculator) - An offline tool for pump room use.

This website's source code is open and available on Github.
