Preview — screen scale is approximate; print output is true size.
Knitting stitches are wider than they are tall, so charting on square paper distorts the design — a circle charted on squares knits as an oval. Cell width÷height here equals your row gauge ÷ stitch gauge, so what you chart is what you knit. Needlepoint mode draws true squares sized to canvas mesh count. Bold rules every N cells make counting fast. Nothing is stored; adjust and reprint freely. Set the printer to 100% / Actual size or the physical scale is lost.
